# User Flows overview

## Job Seeker

1. Landing / Authentication
2. Register / Login
3. Profile Setup + Preferences
4. Upload Resume
5. Resume Parsing + ATS Analysis
6. Personalized Dashboard
7. Jobs -> Search / Filter -> Job Details -> Apply
8. Applications -> My Applications -> Status
9. Interviews -> Select / Setup -> AI Interview -> Result & Feedback
10. Performance -> Report -> Progress Tracker -> Skill Improvement

### Supporting Path
Dashboard -> Resume -> ATS Analysis -> Skill Gaps

## Recruiter
1. Login / Register
2. Company Profile / Setup
3. Recruiter Dashboard
4. Create Job -> Job Details -> Publish
5. Applications / Candidate List
6. Search & Filter -> Candidate Profile
7. Resume + ATS Evaluation
8. Candidate Evaluation
9. Schedule / Conduct Interview
10. Interview Evaluation
11. Shortlist / Reject / Hiring Status
12. Hiring Analytics -> Candidate Insights -> Reports

## UX Intent

The dashboard acts as the central hub for the role-specific workflows. Each major flow has a clear transition to the next task or outcome.
